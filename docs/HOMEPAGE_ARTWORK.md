# Homepage artwork

The four transparent PNGs in `public/homepage/` were generated with the built-in Image Gen tool from the approved Hero, Tracking, repaired Planning, and Insights concepts. Text, navigation, interface previews and section backgrounds remain native HTML/CSS. The approved screenshots are design references, not shipped page images.

The extraction prompts below preserve the object groups, restore areas hidden by the original preview panels, and request real alpha transparency. The planning prompt preserves the repaired paper envelope.

The closing graph (`public/homepage/monthly-result-graph.svg`) is a static export of the existing MonthlyResultChart rendered in `/demo?view=insights`, using only fictional EUR data from March through September 2026. September is incomplete. Its paths, points and axis labels come from that chart; exported CSS variables are resolved, and font/color styles are fixed for the homepage. The graph title and legend are native HTML. This asset was not generated by Image Gen.

## hero

Asset: `public/homepage/hero-still-life.png`

```text
Use case: background-extraction. Asset type: transparent production still-life artwork for CashContour homepage.
Input image: approved webpage concept, reference for the photographed object group.
Extract and faithfully reproduce the object group alone, centered in a tightly framed square transparent PNG with a little transparent breathing room. Keep ONLY the notebook with ivory textured cover, teal spiral binding and mint rectangular label, the receipt peeking above it, the mint ceramic coffee cup at upper right, and teal pen at lower right. Preserve their exact arrangement and angles. Restore the lower-left notebook area hidden by the September panel.
Remove EVERY heading, body text, logo, button, navigation element and interface panel. Remove ALL webpage background, ground plane, page colors and backdrop. Actual alpha transparency, not a checkerboard printed into the image. Receipt markings may be simple abstract lines; no legible words, branding or numbers on objects. Preserve photorealistic texture, studio lighting, realistic shading on objects and delicate transparent contact shadows. No added props, no redesign, no gradients/backdrop, no UI. Match the reference object's colors and framing.
```
